# Andon

Menu bar traffic light for Claude Code and Cursor. Green = ready, yellow = working, red = Claude Code is waiting on a permission prompt (Cursor has no equivalent event — see note below). Named after the manufacturing term for a station light that signals its own status to anyone nearby.

## Install

```bash
bash install.sh
```

This one command handles everything:

- Checks Node.js/npm are installed and new enough, fails with a clear message (not a stack trace) if not
- **Merges** the required hooks into `~/.claude/settings.json` and `~/.cursor/hooks.json` — additive only. Any hooks or settings you already have (prettier, eslint, whatever) are left completely untouched. Safe to re-run any time; won't create duplicate entries.
- **Migrates automatically** if you're upgrading from an earlier build of this tool that used the name "Claude Lights": an old `~/.claude-lights` data folder gets renamed to `~/.andon` (preserving its history), and any hook entries still pointing at the old path get replaced with the new one rather than left alongside it (which would fire the script twice per event).
- Installs `update-status.js` to `~/.andon/`
- Uses the sound file already in `assets/pluck.wav` if present; only synthesizes a fallback tone if that file is missing
- Installs dependencies (Electron)

Then **fully restart** Claude Code and/or Cursor (quit, not just close the window) so they pick up the new hooks, and run:

```bash
npm start
```

to launch the menu bar widget.

## What each hook does

**Claude Code** (`~/.claude/settings.json`):
| Event | Color |
|---|---|
| `UserPromptSubmit`, `PreToolUse` | yellow |
| `Notification`, `PermissionRequest` | red |
| `PermissionDenied` | yellow (back to working) |
| `Stop`, `SessionEnd` | green |

**Cursor** (`~/.cursor/hooks.json`):
| Event | Color |
|---|---|
| `beforeSubmitPrompt`, `beforeShellExecution`, `beforeMCPExecution` | yellow |
| `stop`, `sessionEnd` | green |

Cursor has no clean-permission-pending event the way Claude Code does — its closest equivalent (`beforeShellExecution` returning `{"permission": "ask"}`) is reportedly flaky on some Cursor versions and would require the hook to double as a live permission gate, not just a status reporter. Deliberately left out.

## Recovery paths (why it doesn't get stuck on red/yellow forever)

- `SessionEnd` fires on session close for any reason, catches abandoned sessions
- `PermissionDenied` fires if you decline a prompt (Claude Code only, and only observed to work once you send your next message — see caveat)
- The tray auto-expires any project untouched for 10+ minutes
- Manual "Reset All" in the tray's right-click menu, the catch-all for everything else

**Known caveat**: `PermissionDenied` wasn't observed to fire immediately on Claude Code 2.1.266 during testing — declining a prompt left the state on red until your *next* message (which triggers `UserPromptSubmit` → yellow) or session end.

## The notification sound

`assets/pluck.wav` is a hand-produced sound, not something `generate-pluck.js` outputs — check before assuming otherwise. `generate-pluck.js` only runs as a fallback if `assets/pluck.wav` is missing; if you ever delete that file, running the generator will replace it with a synthesized tone, not your original.

## Building a real macOS installer (.dmg)

```bash
npm install
npm run dist
```

This produces `dist/Andon-0.1.0-arm64.dmg`. Open it, drag the app to Applications, done — no terminal, no Node.js required on the coworker's machine. The hook setup (everything `install.sh` does, migration included) runs automatically the moment the app launches, every launch.

**Two things to know before handing this out:**

1. **Must be built on an actual Mac.** Apple's code-signing and `.dmg`-creation tools don't run on Linux/Windows.
2. **No Gatekeeper signature.** Without a paid Apple Developer account, coworkers will see "Apple could not verify this app is free of malware" the first time they open a copy they downloaded or received (a `.dmg` you build and open locally yourself won't trigger this — the warning only appears once the file has actually been quarantined by being downloaded/transferred). The workaround: **right-click → Open** the first time instead of double-clicking.

If you rename the app again in the future, update `appId` and `productName` in `package.json` together, and note that changing `appId` means macOS treats it as a different app from any previously-installed version — you'll need to manually remove the old one from Applications rather than have the new one overwrite it.

The custom icon is generated by `build-icon.js` (runs automatically as part of `npm run dist`) — it reuses the same circle-renderer as the tray's pulse animation.

## Testing without waiting on a real session

```bash
node ~/.andon/update-status.js yellow
node ~/.andon/update-status.js red
node ~/.andon/update-status.js green
```

## Uninstalling

The hooks live in `~/.claude/settings.json` and `~/.cursor/hooks.json` alongside anything else you have configured — remove the relevant entries by hand if you want them gone (identifiable by their `node ~/.andon/update-status.js ...` command). Then:

```bash
rm -rf ~/.andon
```
